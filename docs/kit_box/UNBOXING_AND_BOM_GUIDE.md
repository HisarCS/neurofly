## 🎁 The All-in-One Kit Experience

Before the Grand Prix competition heat, each student team is handed the **NeuroFly Flight Kit Box**—a premium, organized hardware package containing every single raw mechanical, electronic, and semiconductor part needed to construct an indoor micro-quadcopter and dual-mode remote transmitter from the ground up.

Nothing comes pre-assembled or pre-soldered! Students build their own circuit boards, solder real surface-mount semiconductors, test electrical continuity, tune flight firmware, and pilot their own creations in the arena.

## The Box Itself: a Four-Level Reveal

The kit box is a laser-cut, press-fit finger-jointed box (210 x 140 x 65.25 mm outer) with a **sliding lid** and five **lift-out trays**. It is generated by `hardware/laser/gen_kit_box.py` (Python standard library only) and has an interactive web version at `docs/kit_box/index.html`.

| Layer | Contents | Engraved on the tray |
| :--- | :--- | :--- |
| Lid | NeuroFly logo, "Build. Fly. Compete.", team-number box, optional WS2812 LED window (`--led`) | Finger hole + grip lines |
| Layer 0: Reveal | Welcome card, mission cards 1-4, tools card (85.6 x 54 mm slots) | Logo + tagline |
| Level 1: Build | 1.1 airframe, 1.2 four ducts, 1.3 M2 hardware bag, 1.4 foam tape | Mission hint |
| Level 2: Wire | 2.1 TX PCB, 2.2 drone PCB, 2.3 two XIAO ESP32-C6, 2.4 IMU, 2.5 SMD kit, 2.6 wire + heat-shrink, 2.7 solder + flux, 2.8 LED/buzzer (opt) | Mission hint |
| Level 3: Fly | 3.1 four motors (CW/CCW marked), 3.2 four props, 3.3 drone LiPo, 3.4 TX LiPo, 3.5 TP4056 charger | Mission hint |
| Level 4: Code | 4.1 OLED, 4.2 ToF (opt), 4.3 ADS1115 (opt), 4.4 USB-C cable, 4.5 inputs bag (buttons / gimbals) | Mission hint |

Every tray top plate carries its numbered pocket labels and a mission; the **floor** of the biggest pocket has a hidden "LEVEL n UNLOCKED" message that only appears once the part is lifted out. Pocket sizes are assumptions from typical modules (see the `DECKS` table in the script); measure what you buy and regenerate.

### Materials per box
- 7 sheets of 3 mm plywood or cast acrylic, 400 x 300 mm (the script prints which pieces go on each sheet).
- Wood glue (plywood) or acrylic cement for the trays only; the shell is press-fit.
- 10 mm ribbon, about 0.5 m per box (5 trays x 2 tails).
- Card stock 250-300 gsm for the printed cards (print from the web page, 100 % scale), or sticker paper on thin board.
- Optional: vinyl for the lid team number and a two-colour logo on the front; one WS2812B (5 x 5 mm) for the LED lid.
- 3D printer: TPU/PLA ducts as listed in the BOM.

### Assembling the box
1. Press the base into the front, back and two side walls (tap with a flat block).
2. Test the lid: it slides in from the front through the side-wall slots.
3. Glue each tray: pocket plates on the floor plate, same orientation. The top plate (engraved) goes on top.
4. Tape a ribbon under each floor, tails folding up into the 3.5 mm side gaps.
5. Stack the trays: Level 4 at the bottom, then 3, 2, 1, and the Reveal on top.
6. Slide the lid on, add the cards.

### Cutting
Starting points only (see `hardware/laser/README.md`): **test on scrap first**. Measure sheet thickness, then set `T`, `KERF` and `FIT` at the top of the script.

## 🧑‍🏫 Teacher Box Preparation Checklist (Per 20 Student Teams)

Lab managers and facilitators can prep 20 student kit boxes in approximately 90 minutes using this workflow:

1. **Laser Cutting Batch:**
   - Run `python3 hardware/laser/gen_kit_box.py` (it must print `ALL CHECKS PASSED`), then cut sheets 1-7 (`neurofly_kit_box.dxf`, `neurofly_kit_box_sheet2..7.dxf`) per box. Engrave first, cut last. Cut a scrap test first.
   - Chassis: run `hardware/laser/neurofly_chassis_frame.dxf` on its own sheet (array as many frames as fit).
2. **3D Printing Batch:**
   - Load Bambu / Prusa printers with flexible TPU 95A for ducts and PLA for battery trays and controller shells.
3. **Component Kitting Trays:**
   - Place semiconductors in anti-static ESD zip pouches (labeled with part numbers to prevent confusion during Week 2 soldering).
4. **Box Sealing:**
   - Affix the official team barcode/number sticker on the box lid.
