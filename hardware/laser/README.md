# NeuroFly Laser Cutting

Two designs live here:

1. **Airframe** (`neurofly_chassis_frame.dxf/.svg`): 85 mm wheelbase chassis, red cut paths on layer `CUT`.
2. **Kit box** (`neurofly_kit_box*.dxf/.svg`, generated): the press-fit box with sliding lid and four-level tray stack handed to every team. Web version: `docs/kit_box/index.html`.

## Kit box files

Generated by `gen_kit_box.py` (Python 3 standard library only):

```
python3 gen_kit_box.py            # default 3 mm, kerf 0.15 mm
python3 gen_kit_box.py --led      # lid gets a 5.4 mm WS2812 window
python3 gen_kit_box.py --preview  # also thick-line preview SVGs in preview/ (never cut)
python3 gen_kit_box.py --check-only
```

All sheets are 400 x 300 mm with a 5 mm keep-out. The sheet assignment above is the current output; the script prints it.

### Layers and colours
| Colour | DXF layer | Meaning |
| :--- | :--- | :--- |
| Red `#FF0000` | `CUT` | Through cuts: run last |
| Blue `#0000FF` | `ENGRAVE_VECTOR` | Vector engrave / score lines |
| Black `#000000` | `RASTER_ENGRAVE` | Filled areas (SVG: filled; DXF: closed outlines, hatch in laser software) |
| Grey | `NOTES` | Sheet border and part names. Hide, do not cut |

### Parameters (top of the script)
`T` material thickness (3.0 mm, **measure your sheet**), `KERF` 0.15 mm (every path is offset by KERF/2), `FIT` 0.05 mm press-fit interference (use 0 for acrylic), `W`/`D` outer footprint, `POCKET_CLEAR`, `LID_*` clearances. Finger counts, slot size and box height follow `T`. Part sizes live in the `DECKS` table; measure the parts you actually buy and regenerate.

### Verification built into the script
- 1 mm voxel check of the shell: every wall/base cell owned by exactly one panel, no gaps, no material outside the shell (finger counts are odd and mate).
- Pocket spacing, label overlap, logo clearance and text fit on every tray.
- Pieces inside the 400 x 300 sheet and at least the piece gap apart.
- Written SVG parsed as XML; written DXF re-read entity by entity and bounding box checked; cut counts match between SVG and DXF.

Not verified: an actual cut. Fit, slot clearance and engraving depth depend on your material and machine.

## Box assembly
1. Press the base into front, back and both side walls (finger joints, tap with a flat block; no glue).
2. Check the lid slides in from the front through the side slots; rub a candle stub on the slot if tight.
3. Glue each tray: pocket plates on the floor plate, same orientation, engraved top plate last.
4. Tape a ribbon under each floor so the tails fold up into the 3.5 mm side gaps.
5. Stack Code, Fly, Wire, Build, Reveal; slide the lid in; add the cards.

Cards: print from `docs/kit_box/index.html` at 100 % on 250-300 gsm card (85.6 x 54 mm). Vinyl cutter: team number on the lid and a two-colour logo on the front.

## FabLab CO2 starting settings (50-80 W)

**Test on scrap first.** These are starting points, not measured values for your machine.

| Material | Thickness | Speed | Power | Notes |
| :--- | :---: | :---: | :---: | :--- |
| Baltic birch plywood | 2.5 - 3.0 mm | 18 - 22 mm/s | 65 - 75% | Best strength-to-weight |
| Cast acrylic (PMMA) | 2.0 - 3.0 mm | 12 - 15 mm/s | 70 - 80% | Use `FIT = 0`; flame-polish if desired |
| Delrin | 2.0 mm | 15 - 20 mm/s | 60 - 70% | Crash resistant (airframe) |
| Vector engrave | any | same or faster | low | Tune until visible, no charring |
| Raster engrave | any | fast | low | Tune on scrap |

Cut a 20 mm test square and a finger-joint test to set `KERF`/`FIT` before the real sheets. Never leave a running laser unattended.

## Airframe geometry
Diagonal wheelbase 85 mm; flight controller bay 36 x 36 mm with 30.5 mm M2 holes; 8.5 mm motor pods (friction fit for 8520 cans); 14 x 14 mm weight-reduction cutout and battery tie slots.
